- **AutoTube** *(private)*: a near-autonomous pipeline that produces science & tech explainers for YouTube with local models and Claude, with human review from a phone PWA. See the output on **[@askonaut](https://www.youtube.com/@askonaut)**.
- **[Cris Lorente Nutrición](https://crislorentenutricion.com)**: website, PWA and admin panel for a real online business. *Eleventy, Supabase, 543 tests.*
